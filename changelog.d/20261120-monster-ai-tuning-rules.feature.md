# 怪物 AI 倍率规则

## 变更

- 增加全局、单图和怪物等级区间的倍率匹配，覆盖血量、防御、攻击、移动速度、攻击速度和攻击欲望。单图优先于等级区间，等级区间优先于全局。
- 游戏私有管理 API 可读写持久规则，使用版本校验防止覆盖其他管理员的新修改。配套模式在新副本创建时读取规则并冻结快照，队员复用队长的快照。进图和换房可携带按怪物等级区间编码的倍率；启用需要配套客户端。

## 验证

- 怪物领域包测试和 vet 通过。测试覆盖匹配优先级、等级边界、空配置、输入隔离、规则冲突，以及倍率字段缺失、null、显式零值的区分。
- 本机隔离 MariaDB 验证配置初始化、倍率持久化、旧版本提交冲突、重复初始化保留配置，以及规则更新后队伍继承旧快照、新副本读取新快照。
- 进图和换房包回归通过，覆盖六项倍率编码与单图覆盖。客户端 C++ 解码测试通过。V208 隔离候选的注册回调与倍率查询已在 x86 模拟器执行，覆盖六项倍率、区间边界、原回调交接、无扩展重置和无效数据。属性应用和实机验收仍待完成。
